# UIDAI myAadhaar Portal — Public Portal Error Directory

- **Statutory Authority**: Unique Identification Authority of India
- **Official Helpline listed in project data**: 1947
- **Official Portal URL**: [https://myaadhaar.uidai.gov.in](https://myaadhaar.uidai.gov.in)

## Overview
Decodes Aadhaar demographic updates, document re-validation, mobile number linkage discrepancies, and biometric authentication timeouts.

## Common Citizen Issues & Blockers
- OTP not received on registered mobile
- Name and DOB discrepancy with PAN
- Document re-verification rejected
- Authentication timeout error 500
