# File Upload Failed / Server Refused Document — Meaning, Causes & Safe Resolution

## Quick Answer
> **In Short**: A technical error where the portal refuses to ingest the file, almost always caused by strict file naming constraints, non-standard PDF formats, or file size limits.

- **Service / Portal**: Passport, Driving Licence

## Possible Causes
- **Special characters, symbols, or spaces in file name (e.g., 'my_passport(1).pdf' instead of 'passport.pdf')**: Special characters, symbols, or spaces in file name (e.g., 'my_passport(1).pdf' instead of 'passport.pdf')
- **File size exceeds maximum threshold (often 200 KB or 500 KB limit)**: File size exceeds maximum threshold (often 200 KB or 500 KB limit)
- **Password-protected or encrypted PDF (e.g., downloaded e-Aadhaar with password)**: Password-protected or encrypted PDF (e.g., downloaded e-Aadhaar with password)
- **Unrecognized file extension (e.g., .HEIC from iPhones instead of standard .JPEG or .PDF)**: Unrecognized file extension (e.g., .HEIC from iPhones instead of standard .JPEG or .PDF)

---

## What to Check Before Retrying (Safe Checks)
- [ ] Confirm the file name contains only alphanumeric letters: `document.pdf`.
- [ ] Check that the PDF opens without asking for any password.
- [ ] Inspect file size in File Explorer / Finder properties.

---

## Step-by-Step Resolution

### Step 1: Action 1
Rename the file cleanly: use simple lowercase names like `addressproof.pdf`.

### Step 2: Action 2
Remove passwords from PDFs: Print to PDF or export as an unencrypted file.

### Step 3: Action 3
Compress the file using standard offline tools or print-to-PDF to bring it under 200 KB without losing legibility.

### Step 4: Action 4
Clear browser cache, switch to Google Chrome or Mozilla Firefox, and re-attempt upload.


> [!WARNING]
> **Important Caution**: Do not upload sensitive personal documents to untrusted, ad-supported free online compression websites.


---

## Actions to Avoid
- ❌ Do not upload .webp, .heic, or raw image formats unless explicitly listed on the portal.
