Absolutely. Here’s a 50-point “De-Vibe-Code” UI Audit Checklist you can use before submitting a college project, portfolio project, or interview project.
🎨 1. Visual Design — 10 points
- [ ] Remove unnecessary gradients.
- [ ] Avoid gradient text unless it has a real branding purpose.
- [ ] Use 2–3 core colors maximum.
- [ ] Use a consistent neutral background.
- [ ] Don't make every element rounded.
- [ ] Standardize border radius: e.g. 6px / 8px / 12px.
- [ ] Remove excessive box-shadow.
- [ ] Don't use glassmorphism on every card.
- [ ] Use one consistent icon library.
- [ ] Remove decorative icons that convey no information.
Vibe-coded warning: gradient + glass + glow + rounded-2xl + shadow-xl everywhere.
📐 2. Layout & Spacing — 8 points
- [ ] Establish a spacing system: 4 / 8 / 12 / 16 / 24 / 32 / 48.
- [ ] Align major elements to a consistent grid.
- [ ] Keep content widths intentional.
- [ ] Don't randomly center everything.
- [ ] Maintain consistent card padding.
- [ ] Keep sidebar/header dimensions consistent.
- [ ] Avoid unnecessary empty sections.
- [ ] Check the design at 1366px, 1440px and mobile widths.
Professional test: Hide the colors and look only at alignment. If things don't line up, fix them.
🔤 3. Typography — 7 points
- [ ] Use one primary font family.
- [ ] Establish a clear type scale.
- [ ] Don't use huge 64–80px headings everywhere.
- [ ] Keep body text around 14–16px.
- [ ] Avoid excessive bold text.
- [ ] Keep line lengths readable.
- [ ] Use typography to establish hierarchy rather than colors and shadows.
Example:
Page title        28–32px / 600
Section title     18–20px / 600
Body              14–16px / 400
Metadata          12–13px / 400

🧩 4. Components — 8 points
- [ ] Buttons have a clear hierarchy.
- [ ] One primary CTA per major section.
- [ ] Don't make every button huge.
- [ ] Inputs have proper labels.
- [ ] Forms have validation states.
- [ ] Cards have a genuine purpose.
- [ ] Tables handle empty/loading/error states.
- [ ] Modals aren't being used for things that could be inline.

⚙️ 6. Interaction & UX — 5 points

- [ ] Inputs show focus states.
- [ ] Loading states exist.
- [ ] Errors are handled.
- [ ] Success actions are confirmed.
- [ ] Disabled states are visually clear.
- [ ] Don't animate everything.
Use animation only when it communicates something:
Loading → progress

Navigation → transition
Not:
